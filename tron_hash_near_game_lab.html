🦍 TRON Hash 末四位｜遊戲對照實驗室

先固定顯示基準算法，再用遊戲實際尾碼作比較。所有運算都在此頁面進行，不需要登入或 API Key。

重要：這個工具的基準規則是 SHA-256(區塊高度的十進位文字)，取完整摘要最後 4 個十六進位字元。這不是 TRON 官方 Block ID 算法，也不能保證預測遊戲結果。對照和搜尋是用來檢查資料，不代表找出來的「接近值」能預測下一局。

① 輸入區塊高度，計算 Hash 末四位

不加前綴、不加偏移、不偷偷變更規則。

計算結果會顯示在這裡。

② 和遊戲中的尾碼比較

輸入同一筆遊戲結果的末四位，查看是否相同，以及十六進位尾碼的簡單差距。

先計算區塊，再輸入遊戲尾碼比較。

③ 在附近區塊中搜尋相似尾碼

這是資料探索工具：對每個候選高度套用同一個基準規則，再依「相同位置字元數」與「循環十六進位距離」排序。

輸入目標尾碼後開始搜尋。

④ 批量核對您的實際記錄

每行貼一筆：區塊高度,遊戲尾四位。也接受空格分隔。例：87203186,9E54

貼上實際遊戲記錄，便能計算吻合率。

⑤ 試驗結果怎麼看

如果批量核對的吻合率很低，表示這個基準算法沒有被您的遊戲樣本支持；單靠調整附近區塊，不能讓 SHA-256 本身變得更像遊戲算法。需要再找出遊戲的真實輸入規則，才有可泛化的改進。

本工具不連接遊戲伺服器、不提交資料。頁面重新整理前，請先下載保存您貼入的對照記錄。
